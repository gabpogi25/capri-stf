# Data

This repository contains **no third-party datasets**. Every result in
`experiments/results/` except those listed under "External data" below is
computed from simulated data generated by code in this repository, with the
seed recorded in each CSV header.

## Simulated data (in-repo generators)

| Generator | Used by |
|---|---|
| `synthetic_data/generator.py` (point configurations, regimes, independent bracket estimation) | the simulation experiments and follow-up analyses, baselines |
| `forensics/structure/synthetic.py` (line segments, rendered perspective scenes) | forensic synthetic-null fixture |
| `forensics/video/synthetic.py` (multi-view tracks, rendered mp4 clips) | multi-view and video fixtures, video tests |

## External data (not included)

| Dataset | Used by | Results |
|---|---|---|
| IMC 2025 scenes (Kaggle) | `experiments/run_real_world_baselines.py`, `run_real_images.py` | |
| ETH3D | pencil test between view subsets | |
| GenVideo (GenVideo-Val; GenVideo-100K real clips), not redistributed | `experiments/forensics/real_media_null.py`, `heldout_detection.py` (manifest `videos_v2.csv`) | Gate A passed, gate B failed on the metadata control (`docs/prereg/forensics_video.md`) |
| FaceForensics++ (c23; access by request, terms of use), not redistributed | same runners (manifest `ffpp_c23.csv`) | Gate A passed, gate B failed: no detection (`docs/prereg/forensics_ffpp.md`) |
| Synthbuster, RAISE, GenImage, own captures | `experiments/forensics/real_media_null.py`, `heldout_detection.py`, `compression_sweep.py` (read a manifest, `data/manifests/README.md`) | Not run |

`scripts/download_datasets.py` lists the sources; `scripts/download_imc_dataset.py`
downloads IMC 2025 with your own Kaggle credentials (environment variables or
`~/.kaggle/kaggle.json`; no credential is stored in the repository).

## Trained weights

`ml_models/weights/shape_prior_best.pt` and `confidence_fusion_neural_best.pt` were
trained on simulated data by `ml_models/shape_prior/train.py` and
`ml_models/confidence_fusion/train_neural.py`.

## Photos in the graphical abstracts

`figures/abstracts/photos/sacre_coeur/` holds ten public photos of the Sacré-Cœur from the
hloc sample data (Image Matching Challenge 2021, originally YFCC100M). They are used only for
the illustration in the graphical abstracts (`experiments/run_abstract_photo_demo.py`), not for
any evaluation. Sources and licences: `figures/abstracts/photos/CREDITS.md`.
